# Portifolio - Pedro Benedito

Portfolio estatico para apresentacao profissional.

## Como rodar localmente

Abra o arquivo `index.html` no navegador.

## Como publicar

Depois de editar, envie para o GitHub:

```bash
git add .
git commit -m "Cria base do portfolio"
git push
```

Se o repositorio ja estiver conectado no Vercel, o deploy acontece automaticamente.
